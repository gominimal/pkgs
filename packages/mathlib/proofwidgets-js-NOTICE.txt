Third-party notices: npm code in ProofWidgets4's prebuilt widget JavaScript
============================================================================

ProofWidgets4 commits its infoview JavaScript prebuilt (widget/js/*.js,
bundled by rollup from npm and minified by terser), and its .olean files
embed it via `include_str`, so the `mathlib` package redistributes it. The
minified bundles strip most copyright notices; they are reproduced here.

Generated by packages/mathlib/gen-proofwidgets-notice.py from the exact
npm tarballs the lockfile resolves (each verified against its sha512
`integrity`), covering every non-dev package in the lockfile. That is a
superset of what the bundles contain (react, react-dom and
@leanprover/infoview are rollup externals; others may be tree-shaken).
Licence texts are verbatim from each tarball's root LICENSE / LICENCE /
COPYING / NOTICE files.
