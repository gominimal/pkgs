Rust crates in the Penrose optimizer WebAssembly (ProofWidgets4 df72b02)
============================================================================

ProofWidgets' widget bundles penroseCanvas.js, penroseDisplay.js embed
@penrose/optimizer 3.2.0 (rollup), whose dist/index.js carries a Rust
library compiled to wasm32-unknown-unknown as a base64 string. The mathlib
package ships those bundles inside ProofWidgets' .olean files (via
`include_str`), so it redistributes that object code. Its npm tarball
ships no licence file; the crates below are what was compiled into it.

Generated by packages/mathlib/gen-proofwidgets-wasm-notice.py:
  - the crate set is the normal-dependency closure of penrose's
    `penrose-optimizer` cdylib for wasm32-unknown-unknown, from penrose's
    Cargo.lock and each crate's own Cargo.toml (proc-macro crates and
    build- and dev-dependencies run on the build host and are excluded;
    they are listed at the end), plus the Rust standard library and its
    registry crates for the rustc named in the wasm's `producers` section;
  - every .crate is from static.crates.io, verified against its Cargo.lock
    sha256 checksum, and licence texts are verbatim from its root
    LICENSE / COPYING / NOTICE / COPYRIGHT files (curated upstream text
    where a .crate ships none; source and sha256 in the entry);
  - cross-checked against the wasm's `name` section: every crate whose
    functions the linker kept is in this list (marked [code in wasm]).
    Unmarked crates are dependencies whose code was inlined into a
    caller or stripped; they are listed because they were compiled in.

Where a crate is offered under a choice of licences ("MIT OR Apache-2.0"),
all of the texts it ships are reproduced.
