# CVE-2026-111943: eMudhra intermediate CA private-key compromise. Eight EC P-384
# intermediate keys were generated with tiny private scalars, so anyone can recover
# them from the public certificates. Each key has two certificates: one issued by

# cross-sign from emSign ECC Root CA - G3), and one cross-signed by Sectigo's
# AAA Certificate Services.
#   Incident:   https://bugzilla.mozilla.org/show_bug.cgi?id=2083449
#   NSS root removal (emSign ECC Root CA - G3, NSS 3.131.1):
#               https://bugzilla.mozilla.org/show_bug.cgi?id=2084101
#   Disclosure: https://emudhra.we-have-a-problem.com/
#   Trust-store guidance:
#               https://groups.google.com/a/mozilla.org/g/dev-security-policy/c/0R3XLJL6FuE
#   Go's equivalent SPKI block: https://github.com/golang/go/issues/82345
#
# Format: <cert|spki> <64 lowercase hex>  <free-text note>. '#' starts a comment.
